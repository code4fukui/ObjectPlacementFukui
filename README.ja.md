# Object Placement Fukui


「[Object Placement Example](https://developer.apple.com/documentation/visionos/tracking-points-in-world-space)」サンプルからフォークしました。

アプリがARKitに保存するアンカーの位置と向きを取得し、テーブルや床などの水平面を検出します。検出された平面に3Dオブジェクトを配置します。

詳細については、[ワールド空間における特定のポイントのトラッキング](https://developer.apple.com/documentation/visionos/tracking-points-in-world-space)および[検出された平面へのコンテンツの配置](https://developer.apple.com/documentation/visionos/placing-content-on-detected-planes)を参照してください。

> ARKitに依存する機能はSimulatorでは動作せず、Apple Vision Proでのみ動作します。

## 3Dモデル

本サンプルには以下の3Dモデルが含まれています:
- [xrgourment](https://github.com/code4fukui/xrgourmet)
- [vr-tojinbo](https://github.com/code4fukui/vr-tojinbo/)
